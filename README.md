# STUDIO 042 — 아이패드 셀프 포토부스

아이패드 홈 화면에 올려서 쓰는 포토부스 웹 앱입니다. 손님 화면에서 네 컷을 이어서
찍고 인화지 크기로 합성해 사진 앱에 저장하거나 AirPrint로 뽑습니다. 인화 디자인은
코드를 건드리지 않고 **관리자 화면**에서 직접 고칩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (손님 화면, 촬영, 합성, 관리자 화면) |
| `camera-check.html` | 카메라 점검 페이지. 연결된 카메라를 찾아 영상이 들어오는지 확인 |
| `sw.js` | 오프라인 캐시. 두 번째 실행부터는 인터넷 없이 열립니다 |
| `manifest.json` | 홈 화면 아이콘·이름·전체화면 설정 |
| `icon-180.png`, `icon-512.png` | 앱 아이콘 |
| `make_icons.py` | 아이콘을 다시 만들고 싶을 때 (`python3 make_icons.py`) |

## 올리기 — GitHub Pages (무료, 5분)

카메라는 **https 주소에서만** 열립니다. 아이패드에 파일을 직접 넣어 여는 방식
(`file://`)으로는 카메라가 동작하지 않으니 반드시 호스팅해야 합니다.

1. github.com 에서 새 저장소를 만듭니다. 이름은 아무거나, **Public**으로.
2. 이 폴더의 파일을 전부 올립니다 (Add file → Upload files → 드래그 → Commit).
3. **Settings → Pages** 로 갑니다.
4. Source를 **Deploy from a branch**, 브랜치는 **main**, 폴더는 **/ (root)** 로 두고 Save.
5. 1~2분 뒤 주소가 뜹니다: `https://<아이디>.github.io/<저장소이름>/`

## 아이패드에 설치

1. **Safari로** 위 주소를 엽니다. (크롬 말고 Safari여야 홈 화면 추가가 됩니다.)
2. 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 뜹니다.
4. 처음 촬영 시작을 누르면 카메라 권한을 묻습니다. 허용을 누르세요.

권한을 실수로 거부했다면 **설정 → Safari → 카메라**에서 다시 허용으로 바꿉니다.

# 관리자 화면

시작 화면의 **큰 이름 글씨를 0.75초 길게 누르면** 열립니다. 손님에게는 보이지
않는 입구입니다. 비밀번호는 없으니 손님이 쓰는 자리에서는 아이패드 자체를
**안내 접근(설정 → 손쉬운 사용 → 안내 접근)**으로 잠가두는 쪽을 권합니다.

고친 내용은 **그 자리에서 바로 저장**됩니다. 나가기를 누르면 손님 화면으로 돌아갑니다.

## 카메라

쓸 카메라를 고릅니다. 외장 카메라(후지 카메라를 웹캠으로 쓰거나 HDMI 캡처카드)를
연결했다면 여기서 골라야 포토부스가 그 카메라를 씁니다. 고르지 않으면 기기의 기본
카메라가 쓰입니다.

이름이 "카메라 1, 카메라 2"로만 보이면 아직 권한을 허용하지 않은 것입니다. 아래 보정
미리보기에서 카메라를 한 번 켜서 허용한 뒤 **카메라 다시 찾기**를 누르세요.

정해둔 카메라가 빠지면 기본 카메라로 알아서 돌아가고, 촬영이 멈추지 않습니다.

외장 카메라는 좌우를 뒤집지 않습니다. 거울처럼 뒤집는 건 기기 전면 카메라일 때만입니다.

### 카메라가 잡히는지 미리 확인하기

같은 주소 뒤에 `camera-check.html` 을 붙여 열면 점검 페이지가 나옵니다
(`https://<아이디>.github.io/<저장소>/camera-check.html`). 연결된 카메라를 전부
찾아 이름과 해상도를 보여주고, 고른 카메라의 영상이 실제로 들어오는지 확인합니다.
후지 카메라가 목록에 없을 때 무엇을 봐야 하는지도 그 페이지에 적어뒀습니다.

## 보정과 색감

촬영 화면에 보이는 것이 그대로 인화됩니다. 미리보기와 합성이 같은 숫자를 쓰기
때문입니다.

**카메라 켜기**를 누르면 내 얼굴을 보면서 값을 맞출 수 있습니다. 슬라이더를
움직이면 바로 반영됩니다.

| 항목 | 하는 일 |
|---|---|
| 밝기 | 전체를 밝게/어둡게 |
| 대비 | 밝은 곳과 어두운 곳의 차이 |
| 채도 | 색의 진하기. 0이면 흑백 |
| 피부 보정 | 얼굴을 부드럽게. 30~50이 자연스럽고, 70을 넘으면 눈·머리카락도 뭉갭니다 |
| 먹색 띄우기 | 검은 부분을 들어 올려 필름 같은 느낌 |
| 비네팅 | 가장자리를 어둡게 |
| 세피아 | 갈색빛 옛날 사진 느낌 |
| 색상 돌리기 | 색 전체를 다른 색조로 회전 |

**색감 덧씌우기**가 원하는 색을 넣는 부분입니다. 색을 고르고 세기를 올리면 그
색이 사진 전체에 입혀집니다. 섞는 방식이 느낌을 바꿉니다.

- **은은하게** — 밝은 곳은 그대로 두고 중간 톤에만 색이 섞입니다. 대부분 이게 맞습니다.
- **또렷하게** — 대비가 같이 올라가면서 색이 진하게 들어갑니다.
- **곱하기** — 전체가 그 색 쪽으로 어두워집니다. 노을빛 같은 느낌.
- **밝히기** — 전체가 그 색 쪽으로 밝아집니다. 뿌연 느낌.
- **색만 입히기** — 밝기는 그대로 두고 색만 바꿉니다. 거의 단색 사진이 됩니다.

세기가 0이면 아무것도 입히지 않습니다.

보정은 추가·복제·삭제할 수 있고, **손님 화면에 보이기**를 끄면 목록에서만 남습니다.
**보정만 기본값으로**는 보정 목록만 되돌리고 인화 방식은 건드리지 않습니다.

기본으로 들어 있는 여섯 가지는 원본, 화사하게, 뽀샤시, 흑백, 필름, 쿨톤입니다.
전부 고칠 수 있으니 마음에 드는 것을 복제해서 바꾸는 쪽이 편합니다.

## 인화 방식

인화 디자인 하나하나가 "인화 방식"입니다. 목록에서 골라 편집하고, 새로 만들거나
복제하거나 지울 수 있습니다. **손님 화면에 보이기**를 끄면 목록에서만 남고 손님
화면에는 나타나지 않습니다. 작업 중인 디자인을 숨겨둘 때 씁니다.

## 인화지 크기

300dpi 기준 픽셀입니다. 1200 × 1800 이면 4 × 6 인치로 인쇄됩니다. 프리셋에 없는
크기는 직접 입력하면 되고, 인쇄할 때 앱이 이 크기에 맞춰 용지를 자동으로 잡습니다.

## 배경과 프레임

- **배경**은 사진 **아래**에 깔립니다. 바탕 무늬나 색지 역할입니다.
- **프레임**은 사진 **위**에 덮입니다. 투명 PNG로 만들어야 사진이 가려지지 않습니다.

둘 다 인화지 크기에 맞춰 늘어나므로, 포토샵에서 인화지와 **같은 픽셀 크기**로
만드는 게 가장 깔끔합니다. 예를 들어 세로 4컷이면 1200 × 1800 PNG.

올린 이미지는 **저장할 때 인화지 크기로 자동으로 줄입니다.** 카메라 원본처럼 큰
사진을 그대로 들고 있으면 합성할 때 브라우저의 캔버스 메모리가 넘쳐서 결과가
잡티로 나오기 때문입니다. 그래서 큰 사진을 올려도 되지만, 인화지 크기에 맞춰
직접 만든 이미지가 화질이 가장 좋습니다. 프레임은 투명도를 지키려고 PNG로,
배경은 용량을 줄이려고 JPEG로 저장됩니다.

프레임을 쓸 때 순서는 이렇습니다. 먼저 관리자 화면에서 사진 칸을 원하는 자리에
놓고, 그 좌표에 맞춰 포토샵에서 프레임을 그린 뒤 올립니다. 편집 화면에서는 프레임이
반투명하게 보여서 칸 위치를 맞추기 쉽습니다.

## 사진 칸

편집 화면에서 **끌어서 옮기고**, 선택한 칸의 **오른쪽 아래 손잡이로 크기를 바꿉니다**.
정확한 값이 필요하면 아래 숫자 칸에 직접 넣으면 됩니다.

**몇 번째 사진**이 중요한 설정입니다. 칸에 적힌 번호가 곧 몇 번째로 찍은 사진인지를
가리킵니다. 여러 칸에 같은 번호를 주면 같은 사진이 그 칸들에 들어갑니다. 세로 4컷
인화지가 왼쪽 오른쪽 같은 사진인 이유가 이것이고, 그래서 8칸이지만 **4번만 찍습니다**.
촬영 컷수는 번호 중 가장 큰 값으로 자동 결정됩니다.

도구 세 가지가 있습니다.

- **가로로 고르게** — 모든 칸을 한 줄로 균등 배치합니다.
- **세로로 고르게** — 모든 칸을 한 열로 균등 배치합니다.
- **두 줄로 복제** — 왼쪽 절반에 있는 칸들을 오른쪽에 같은 번호로 복제합니다.
  나눠 갖는 인화지를 만들 때 씁니다.

## 글자

`{brand}` 는 손님이 시작 화면에서 정한 이름으로, `{date}` 는 촬영 날짜로 바뀝니다.
그 밖의 글자는 적은 그대로 찍힙니다. 글자도 편집 화면에서 끌어서 옮길 수 있습니다.

좌표의 **Y는 글자의 밑선(baseline)** 입니다. 글자 크기를 키우면 위로 자랍니다.

## 절취선

가운데를 잘라 나눠 갖는 인화지에 점선을 넣습니다. 세로선 X 위치만 정하면 됩니다.

## 미리보기

더미 사진(1, 2, 3, 4 번호가 찍힌 색 사각형)으로 **실제 합성 과정을 그대로 돌려서**
결과를 보여줍니다. 카메라를 켜지 않고 디자인만 확인할 때 쓰세요. 결과 화면에서
인쇄까지 눌러보면 용지에 어떻게 들어가는지도 확인됩니다.

## 설정 내보내기 / 가져오기

올린 배경·프레임 이미지까지 JSON 파일 하나에 담깁니다. 아이패드를 바꾸거나 설정을
백업할 때 쓰세요. 가져오기를 하면 **지금 설정을 전부 덮어씁니다**.

## 초기화

모든 인화 설정과 올린 이미지를 지우고 처음 상태로 되돌립니다. 되돌릴 수 없으니
그 전에 내보내기를 해두는 게 안전합니다.

## 인쇄할 때

AirPrint 프린터가 같은 와이파이에 있으면 바로 뽑힙니다. 앱이 인화지 크기에 맞춰
용지 크기를 알아서 지정합니다. 인쇄 창에서 두 가지만 확인하세요.

- **머리말·꼬리말 끄기** — 켜져 있으면 날짜와 파일 경로가 같이 찍힙니다. CSS로는
  못 끄는 브라우저 설정입니다. Safari는 "머리말 및 바닥글" 체크 해제, Chrome은
  더보기 설정 → "머리글 및 바닥글" 해제.
- **용지와 여백 없음(Borderless)** — A4에 뽑으면 가운데 작게 들어갑니다.

## 알아둘 점

- 설정과 이미지는 그 **브라우저 안에만** 저장됩니다(IndexedDB). 사파리 기록을 지우면
  같이 지워지니, 공들여 만든 디자인은 내보내기로 백업해 두세요.
- 뷰파인더는 **첫 번째 칸의 비율**로 보여줍니다. 칸마다 비율이 다르면 촬영은 화면
  전체를 담아두고 합성할 때 칸마다 가운데를 잘라 씁니다.
- 전면 카메라는 거울처럼 좌우를 뒤집어 저장합니다. 화면에 보이는 모습과 인화물이
  같아지도록 한 것이고, 후면 카메라는 뒤집지 않습니다.
- 앱을 고친 뒤 아이패드에 반영되지 않으면 `sw.js` 첫 줄의 `booth-v7` 숫자를 올리고
  다시 올리세요. 오프라인 캐시가 옛날 파일을 붙잡고 있는 겁니다.
